# CatQuest Extended Voice Packs

Public catalog and contribution hub for voice packs compatible with CatQuest Extended.

For simple installation and project information, visit the [CatQuest Extended website](https://catquest.mvse.ws/).

## Published packs

The current approved pack is distributed from the project server:

- [CatQuestExtended_Voices.zip](https://catquest.mvse.ws/downloads/CatQuestExtended_Voices.zip) — full Russian quest voice pack for WoW 3.3.5a.

The repository stores pack metadata, manifests, attribution, and contribution rules.
Large audio archives are intentionally not committed to Git. Each published pack
has its own license and attribution information.

## Contributing a voice

You can propose a new voice, language, client profile, or replacement track through
a GitHub Issue or Pull Request. Start with [CONTRIBUTING.md](CONTRIBUTING.md) and
use the [pack specification](PACK-SPEC.md) for metadata.

There are three simple ways to help:

- request a missing quest voice;
- submit a ready recording for a quest or track;
- propose a new language pack.

Choose the matching issue template in the repository's **Issues → New issue** menu.
You can open the [new issue page directly](https://github.com/mvsews/catquest-voice-packs/issues/new/choose).

Please submit only audio that you created yourself or are legally allowed to
redistribute. Include the voice actor, language, client profile, source, and license.
Full packs should not be uploaded to this repository; approved audio is reviewed,
packaged, and published through the CatQuest Extended distribution server.
