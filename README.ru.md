# Голосовые паки CatQuest Extended

Публичный каталог и площадка для предложений по голосовым пакам CatQuest Extended.

Для простой установки и информации о проекте используйте [сайт CatQuest Extended](https://catquest.mvse.ws/).

## Опубликованные паки

Текущий одобренный пак распространяется с сайта проекта:

- [CatQuestExtended_Voices.zip](https://catquest.mvse.ws/downloads/CatQuestExtended_Voices.zip) — полный русский пак озвучки квестов для WoW 3.3.5a.

В репозитории хранятся метаданные паков, манифесты, сведения об авторах и правила
контрибьюта. Большие аудиоархивы намеренно не добавляются в Git. Для каждого
опубликованного пака указываются его лицензия и атрибуция.

## Как предложить озвучку

Через GitHub Issue или Pull Request можно предложить новый голос, язык, профиль
клиента или замену отдельной дорожки. Сначала прочитайте
[CONTRIBUTING.md](CONTRIBUTING.md) и описание формата в [PACK-SPEC.md](PACK-SPEC.md).

Есть три простых варианта участия:

- попросить озвучить отсутствующий квест;
- предложить готовую запись для квеста или отдельной дорожки;
- предложить новый языковой пак.

Выберите подходящий шаблон в разделе репозитория **Issues → New issue**.
Можно сразу открыть [страницу нового предложения](https://github.com/mvsews/catquest-voice-packs/issues/new/choose).

Предлагайте только аудио, которое создали сами или имеете право распространять.
Укажите актёра озвучки, язык, профиль клиента, источник и лицензию. Полные паки
не загружайте в этот репозиторий: одобренные дорожки проверяются, собираются и
публикуются через систему распространения CatQuest Extended.

## Содержимое репозитория

- [`packs/catalog.json`](packs/catalog.json) — каталог опубликованных паков;
- [`PACK-SPEC.md`](PACK-SPEC.md) — формат манифеста и правила именования;
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — процесс предложения и проверки.
